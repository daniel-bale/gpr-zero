# GPR-Zero: Improving Geopolitical Risk Assessment

This project implements a novel approach to geopolitical risk (GPR) index construction using LLM-based methods, with a focus on application to Taiwan.

## Project Overview

GPR-Zero aims to address limitations in current Geopolitical Risk (GPR) index methodologies by:

1. Using LLMs to generate Chinese keyword dictionaries without human intervention
2. Calculating and comparing GPR indices derived from local Chinese-language news sources
3. Implementing zero-shot LLM classification of geopolitical risk in news articles

For a detailed project description, see [project-goal.md](project-goal.md).

## Prior Work Integration

This project builds upon and extends prior work in GPR index calculation:

- The `data/dictionaries/` directory includes both original dictionaries generated by our LLM approach as well as reference dictionaries from Caldara & Iacoviello (2022) and Yeu-Tong Lau (2024)
- The `data/indices/` directory contains both newly calculated indices and reference indices from prior work for comparative analysis
- These existing indices and dictionaries serve as benchmarks to validate our approach and demonstrate improvements

## Installation

This project uses [`uv`](https://github.com/astral-sh/uv) for Python package management and virtual environment handling. If you're not familiar with uv, see the [official documentation](https://docs.astral.sh/uv/).

```bash
# Clone the repository
git clone https://github.com/yourusername/gpr-zero.git
cd gpr-zero

# Create a virtual environment with Python 3.12
uv venv

# Install all dependencies
uv sync
```

### Tool Management

This project uses uv to manage development tools:

```bash
# Install development tools (user-wide)
uv tool install ruff      # Install the Ruff linter/formatter
uv tool install pytest    # Install pytest
```

## Usage

### Dictionary Generation

```bash
uv run main.py generate-dictionary --strategy direct --output my_dictionary
```

### GPR Index Calculation

```bash
uv run main.py calculate-index --dictionary data/dictionaries/my_dictionary.json --source chinatimes --normalize
```

### LLM Classification

```bash
uv run main.py classify --source chinatimes --start-date 2020-01-01 --end-date 2020-12-31
```

### Index Analysis

```bash
uv run main.py analyze --indices data/indices/gpr_index_chinatimes.csv data/indices/gpr_index_ltn.csv --names "China Times" "Liberty Times"
```
